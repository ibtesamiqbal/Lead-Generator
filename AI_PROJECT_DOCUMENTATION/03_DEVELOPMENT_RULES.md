# Development Rules & Workflow

## Core Principles
1. **Phase-by-Phase Development**: Never implement multiple phases in a single step. Each phase must produce working software.
2. **Correctness Over Speed**: Always prioritize reliability, maintainability, and clean modular code.
3. **Repository as Source of Truth**: Never depend on conversation history; documentation files must reflect real project state.
4. **Single Responsibility**: Every module, class, and function must have a single clear purpose.
5. **No Anti-Loops**: If an approach fails repeatedly, stop, identify the root cause, document it, and pick an alternative.

## Workflow Sequence
Understand → Research → Plan → Explain → Implement → Test → Document → Review → Commit → Continue.
