# Git Workflow & Commit Guidelines

## Core Rules
1. **Clean History**: Never commit broken code, failing tests, or unformatted files.
2. **Phase Completion**: Every phase must end with passing tests, updated status documentation, and a clean commit.
3. **Commit Messages**: Follow Conventional Commits format (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`).
4. **No History Rewrites**: Avoid `git rebase` on shared branches or force pushes.
